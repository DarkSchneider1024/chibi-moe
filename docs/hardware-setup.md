## 🛠️ 第一步：準備組件與焊接

在開始用杜邦線連接之前，請確認完成以下事項：
1. **擴大機模組 (MAX98357A)**：將排針焊接在側邊排孔，並將綠色的 **2-Pin 螺絲端子** 焊接在輸出端。
2. **喇叭連接**：用螺絲起子將擴大機綠色端子的螺絲旋鬆，插入喇叭的紅線（正極）與黑線（負極），然後將螺絲鎖緊。
3. **麥克風模組 (INMP441)**：將排針焊接好。
4. **直流減速馬達焊接**：將紅黑雙色導線焊接在馬達尾端的金屬銅片小孔上。一個焊紅線、一個焊黑線，如下圖所示：

## 🔌 第二步：杜邦線對照表 (引腳連接)

請使用杜邦線將模組的引腳與 **ESP32-S3-CAM** 進行連接：

### 🔊 1. 喇叭放大器 (MAX98357A) 接線
* 作用：讓機器人能夠播放聲音。

| 擴大機 (MAX98357A) 針腳 | 連接至 ESP32-S3 針腳 | 說明 |
| :--- | :--- | :--- |
| **VIN** | **5V** (左側最上方) | 供電電源 (接 5V 聲音會更響亮) |
| **GND** | **GND** (右側最下方) | 接地 |
| **LRC** | **G1** (右側第 3 針) | I2S 左右聲道切換訊號 |
| **BCLK** | **G2** (右側第 4 針) | I2S 時鐘訊號 |
| **DIN** | **G42** (右側第 5 針) | I2S 音訊資料輸出 |

---

### 🎙️ 2. 麥克風 (INMP441) 接線
* 作用：讓機器人能夠聽懂您說的話。

| 麥克風 (INMP441) 針腳 | 連接至 ESP32-S3 針腳 | 說明 |
| :--- | :--- | :--- |
| **VDD** | **3V3** (左側最下方) | 供電電源 (3.3V) |
| **GND** | **GND** (共用接地) | 接地 |
| **L/R** | **GND** (共用接地) | 聲道選擇，接 GND 代表左聲道 |
| **SCK** | **G41** (右側第 6 針) | I2S 錄音時鐘訊號 |
| **WS** | **G40** (右側第 7 針) | I2S 錄音聲道切換訊號 |
| **SD** | **G39** (右側第 8 針) | I2S 錄音資料輸入 |

---

### 🚗 3. 雙馬達驅動器 (L9110S / MX1508 / L298N) 接線
* 作用：接收 ESP32-S3 指令來控制左右輪子的馬達。
* 接線特點：使用右側一整排相鄰的針腳，方便集中接線。

| 驅動板引腳 (以 L9110S 為例) | 連接至 ESP32-S3 針腳 | 說明 |
| :--- | :--- | :--- |
| **A-1A** | **G19** (右側第 19 針) | 左馬達正轉訊號 |
| **A-1B** | **G20** (右側第 18 針) | 左馬達反轉訊號 |
| **B-1A** | **G21** (右側第 17 針) | 右馬達正轉訊號 |
| **B-1B** | **G47** (右側第 16 針) | 右馬達反轉訊號 |
| **GND** | **GND** (共用接地) | 訊號地線 (必須與 ESP32 共地) |
| **VCC** (驅動供電) | 電池盒紅線 (正極) | 馬達電源 (請勿直接接板子的 3.3V) |
| **GND** (驅動電源) | 電池盒黑線 (負極) | 電池負極 |

> [!WARNING]
> 馬達驅動板的馬達供電 (VCC/VM) **絕對不可直接接在 ESP32 的 3.3V 腳位上**！馬達瞬間電流很大，會直接燒毀板子或導致當機重啟。必須使用附帶的「4 節 AA 電池盒」作為獨立電源供應給馬達。

## 💡 貼心小技巧：如何解決多條 GND 線的連接？

由於 ESP32-S3 開發板上只有一個標示為 `GND` 的引腳，但我們有 3 條線需要接地（放大器的 GND、麥克風的 GND、以及麥克風的 L/R 腳位）。

**您可以選擇以下簡易方式解決：**
1. **使用麵包板（推薦，最簡單）**：將 ESP32-S3 的 `GND` 用一根杜邦線接到麵包板的藍色/負極整排孔上，再將其他 3 根 GND 線也插到同一排。
2. **絞線法**：將這三根 GND 線的另一端剝皮扭在一起，用單條杜邦線連接到 ESP32-S3 的 `GND`，並用絕緣膠帶包覆。

## 🎤 語音控制與小車動作控制

除了使用控制台上的手動搖桿之外，您還可以直接對著 Chibi-Moe 語音助理說話來命令小車進行各種移動！

### 1. 啟用語音控制功能 (重要)
在網頁版面或操控台中，點擊「設定」(Gear 圖示)，請確保將 **Machine Ops** 功能勾選為「**開啟 (True)**」狀態。這個設定將會把控制小車動作的 Tool（工具函數）賦予 Gemini 模型。

### 2. 常用語音命令詞示例
當您按住 **BOOT** 鍵（或點擊網頁麥克風）開始錄音時，可以直接說出以下詞彙：

* **直行運動**：
  * 「**往前走**」/「**前進**」/「**開車**」 ➔ 小車將向前直行。
  * 「**向後退**」/「**後退**」/「**倒車**」 ➔ 小車將向後退行。
* **轉向控制**：
  * 「**向左轉**」/「**左轉**」 ➔ 小車將向左原地自轉。
  * 「**向右轉**」/「**右轉**」 ➔ 小車將向右原地自轉。
* **趣味動作**：
  * 「**旋轉**」/「**轉圈圈**」/「**跳舞**」 ➔ 小車將執行旋轉跳舞動作。

### 3. 自訂動作時間
Gemini 能夠理解您設定的運動時間，例如：
* 「**往前走三秒鐘**」 ➔ AI 將自動識別並呼叫馬達轉動 3000ms（3秒）後自動停止。
* 「**向右轉半秒**」 ➔ 馬達將會轉動 500ms（0.5秒）後自動停止。

*(註：若命令中未包含時間，預設的運作時間為 500ms 至 1000ms。)*

## 📶 WiFi 連線與更改設定指南

小車韌體內建了熱點設定頁面，無論是第一次開機還是之後需要更改連線的 WiFi，都可以依照以下說明進行：

### 1. 第一次開機連線設定
1. 將燒錄好韌體的小車開機。
2. 小車因為沒有連線過 WiFi，會自動開啟一個名為 **`Chibi-Moe-Setup`** 的無密碼臨時 WiFi 熱點。
3. 用您的手機或電腦連線到此 `Chibi-Moe-Setup` WiFi。
4. 連線後會自動彈出設定網頁。若無彈出，請開啟瀏覽器輸入 `192.168.4.1`。
5. 點擊 **Configure WiFi**，選擇您的 WiFi 熱點並輸入密碼，接著在下方填入後端伺服器的 Host 與 Port，最後點選 **Save** 即可。

### 2. 更改 WiFi（重設網路記錄）
當您帶小車到新環境或想更換 WiFi 密碼時，請使用硬體重設功能：
1. 先確保開發板處於關機狀態（或準備按下板上的 `RST` 重啟鍵）。
2. **長按板子上的 `BOOT` 按鈕 (GPIO 0) 不放**，接著開機或重啟。
3. **持續按住 `BOOT` 鍵 3 秒鐘以上**，直到序列埠或狀態重啟。
4. 舊的 WiFi 紀錄便會被清除，小車重啟後會再次開啟 **`Chibi-Moe-Setup`** 臨時熱點。
5. 依照「第一次開機連線設定」重新連線並設定新的 WiFi 帳號與密碼即可！
