# Chibi-Moe 系統 UI/UX 操作與測試說明書

本手冊指導您如何操作 Chibi-Moe 語音助理 Web 前端系統，包含「一鍵切換本地/遠端後端」、「同步設定至機器人」以及「語音對話模式切換」等功能。

---

## 💻 1. 後端切換功能 (本機 vs 雲端)

在頁面最上方狀態列右側，您會看到後端切換按鈕：
* **`☁️ 雲端後端`**：連線至 K8S 雲端伺服器（預設網址 `wss://chibi.carrot-atelier.online`）。
* **`💻 本機後端`**：連線至您本機運行的 Docker 後端伺服器。

### 🔄 如何一鍵切換至本地測試：
1. 點擊 **`☁️ 雲端後端`** 按鈕。
2. 系統會跳出提示框，要求您輸入您電腦在區域網路中的 IP 地址（例如 `192.168.10.171`）。
3. 輸入後，網頁端會透過目前連線的雲端伺服器，**將此 IP 同步命令發送給機器人小車**，機器人會自動更新配置並重啟以連回您的本機。
4. **HTTPS 混合內容 (Mixed Content) 繞過機制**：由於 Vercel 正式環境為安全 HTTPS 協定，瀏覽器安全政策嚴禁連線至非安全 IP（`ws://192.168.x.x`）。因此在 HTTPS 環境下，網頁端會**自動連線至 `ws://127.0.0.1:3001`**（瀏覽器特別允許 localhost 作為安全上下文），而小車則連線至您的區域網路 IP，兩者在本機 Docker 後端完美交會！

---

## ⚙️ 2. 同步設定至機器人 (Sync to Robot)

在網頁下方的 **設定** (齒輪圖示) 面板中：
* **同步到機器人按鈕**：位於「後端 WebSocket 網址」欄位右側。
* **功能**：當您的網頁與小車同時連線在同一個伺服器上時，您可以隨時修改網址欄位，然後點選「同步到機器人」。這會直接下發 `update_config` 指令，使小車修改配置並自動重啟連往新後端，無須每次都長按實體小車上的 `BOOT` 鍵重新配網。

---

## 🎙️ 3. 語音收發對話模式

在網頁下方控制列左側，以及「機器人操控台」面板的錄音鍵下方，您可以切換語音模式：

### 📱 3.1 手機模式 (Phone Mode)
* **特點**：使用手機/電腦的麥克風收音，並從**網頁（手機）喇叭播放 AI 回應**。
* **適用場景**：當機器人小車處於關機或離線狀態時，您仍然可以將 Chibi-Moe 作為一般的手機語音助理進行對話。在此模式下，小車是否連線不會影響對話運作。

### 🤖 3.2 機器人模式 (Robot Mode)
* **特點**：使用手機的麥克風收音，但 **AI 的語音回應會直接從小車的喇叭（MAX98357A）播放出來**！
* **連線偵測**：在此模式下，一旦您說話並放開錄音，系統會**自動偵測小車連線狀態**。若小車處於離線狀態，系統會立即拋出 `⚠️ 傳送失敗：機器人小車離線中，無法使用機器人模式。` 的警示，確保使用者獲得即時的 UI 反饋。

*(註：若您是直接按小車上的實體 BOOT 鍵收音，小車會自動錄音並透過小車本身的喇叭播放回應。)*

---

## ⚠️ 4. 超時與異常錯誤反饋

系統具備了即時防卡死反饋機制：
* **12 秒超時防護**：若因 Gemini API 或網路傳輸異常導致伺服器 12 秒內沒有回傳語音，網頁端會自動中斷等待狀態，並輸出 `⚠️ 語音對話超時，請稍後重試。`。
* **斷線即時反饋**：若在「錄音中」或「AI 處理中」時 WebSocket 斷線，系統會立刻重設狀態為 `idle` 並在對話框輸出 `⚠️ 與伺服器的連線已中斷。`，避免頁面顯示卡在「處理中」的狀態。
