麥克風 + 喇叭 接線圖解

ESP32-S3-CAM（GOOUUU）× INMP441 麥克風 × MAX98357A 功放 × 3W 喇叭 —— 腳位對應韌體 firmware/src/main.cpp，接完即可用。

接線總圖

5V 電源 3.3V 電源 GND 共地 麥克風資料 SD 麥克風 WS 麥克風 SCK 喇叭資料 DIN 喇叭 BCLK 喇叭 LRC

麵包板實體配置圖

5V（紅軌） 3.3V（直連） GND（藍軌） SD→G39 WS→G40 SCK→G41 DIN→G42 LRC→G1 BCLK→G2
  • 麥克風（第 5–7 列）跨中央溝槽插：一邊三支腳在上半區、另一邊三支在下半區，兩排腳才不會短路。接線接在同一列的空孔（同列五孔相通）。
  • 功放（第 17–23 列）七支腳插同一橫排，每支腳佔一列；接線同樣插各腳同列的空孔。GAIN、SD（第 20、21 列）懸空不接。
  • 圖中模組腳位順序是常見排列，實際請以你模組板上的絲印文字為準——找到 VDD/SD/WS/SCK 等字樣後照顏色對應接到 ESP32 即可，位置差一兩列無妨，重點是「腳名對腳名」。
  • ESP32 板身較寬，不上麵包板，直接用公對母杜邦線從板上排針飛線過來。
⚠️ 上電前必讀
  • INMP441 只能接 3.3V——接到 5V 會燒毀麥克風。
  • MAX98357A 的 Vin 接 5V（2.5–5.5V 皆可），喇叭鎖進綠色端子，正負反了只是相位相反、不會壞。
  • 兩塊模組的 GND 都必須與 ESP32 共地，麥克風 L/R 也接 GND（韌體設定為左聲道）。
  • 你照片裡的 MAX98357A 排針和綠色端子還沒焊，要先焊上才能插麵包板。INMP441 的黃色排針已附。

組裝步驟

  1. 焊接：把黃色排針焊到 MAX98357A（元件面朝上、針腳朝下插麵包板），綠色螺絲端子焊到喇叭輸出孔。
  2. 佈局：兩塊模組插上麵包板中間區，跨槽插避免腳位互相短路；ESP32 板太寬可不上麵包板，直接用母對母杜邦線飛線。
  3. 先接電源：紅線 5V→功放 Vin、橘線 3V3→麥克風 VDD、黑線把兩塊 GND 與 L/R 全部接回 ESP32 GND（可用麵包板藍色軌做共地）。
  4. 再接訊號：照上表接六條訊號線，顏色跟圖例一致最好查錯。
  5. 檢查後上電：確認 VDD 沒接到 5V、無相鄰腳短路，再插 USB。

如何用麵包板測試

麵包板的連通規則：中間區域每一橫排的 a–e 五孔彼此相通、f–j 五孔相通，中央溝槽兩側不相通；兩側長條的紅（＋）藍（－）電源軌是整條縱向相通。模組插上去之後，同一排剩下的孔就是它那支腳的延長點，杜邦線插旁邊的孔即可，不用擠同一個孔。

  • 把 ESP32 的 5V 接到紅軌、GND 接到藍軌，之後功放 Vin 從紅軌取電、所有 GND（含麥克風 L/R）都插藍軌——共地一次搞定。
  • ⚠️ 麥克風的 3.3V 不要從紅軌拿（紅軌是 5V）！用一條橘線直接從 ESP32 的 3V3 腳拉到麥克風那排。
  • 部分麵包板電源軌中間有斷點（紅藍線中斷處），跨過去要加跳線。

分階段點亮（每一階段通過再進下一步，出問題馬上知道是哪段）：

  1. 只接電源：接好 5V/3V3/GND 就上電。摸兩塊模組不應發燙、ESP32 正常連線（網頁顯示機器人已連線）。有燙感立刻斷電查短路。
  2. 先測喇叭（不用接麥克風）：接好功放三條訊號線＋喇叭，在網頁輸入文字或按網頁麥克風跟 AI 對話並勾選輸出到機器人——喇叭發出 TTS 語音即通過。沒聲音先查 DIN/BCLK/LRC 三條有沒有插錯排。
  3. 再測麥克風：接好麥克風四條線（SD/WS/SCK＋L/R 接地），按住 BOOT 說一句話再放開。看後端 log（localhost:3001/status）出現收到 audio、Gemini 回覆即通過。若 AI 說聽不清楚，檢查 L/R 是否確實接地、SD 線是否插對排。
  4. 全鏈路：按住 BOOT 提問 → 放開 → 喇叭回答。完成！

常見麵包板陷阱：杜邦線沒插到底（半接觸最難查）、模組沒跨中央溝槽導致左右腳短路、訊號線超過 20cm 造成 I2S 雜訊。出現雜音先把線換短、重插一遍。

接好之後的測試流程

  1. ESP32 上電，等網頁狀態列顯示「機器人 已連線」。
  2. 網頁 設定 裡填入 Gemini API Key（後端重啟後要重新送出一次設定——重新整理網頁即可）。
  3. 按住 ESP32 板上的 BOOT 鍵說話（最長 8 秒），放開後送出。
  4. 後端 log 應依序出現：收到音訊 → Gemini 回覆 → 送 TTS 到喇叭；喇叭播出回答就全通了。
  5. 對它說「往前走」「轉圈圈」可測 AI 呼叫馬達指令（Machine Ops 需開啟；馬達未接時看 log 確認即可）。

提示：BOOT 鍵同時是燒錄鍵，若按住時重開機會進下載模式——正常使用（上電後才按）不受影響。錄音期間相機串流會自動暫停，屬正常行為。
